# ATM Interface

## Project Description

This is a simple ATM Interface project developed using Java.

The project allows the user to:
- Deposit money
- Withdraw money
- Check account balance
- Exit the application

This project is created using basic Object-Oriented Programming (OOP) concepts.

---

## Features

- Deposit amount
- Withdraw amount
- Check balance
- Simple menu-driven program
- User-friendly output

---

## Technologies Used

- Java
- VS Code
- Scanner Class

---

## Files

- Main.java - Starts the program.
- ATM.java - Displays the ATM menu and handles user input.
- BankAccount.java - Stores the balance and performs deposit, withdrawal, and balance check.

---

## How to Run

1. Open the project in VS Code.
2. Open the Terminal.
3. Compile the Java files:

```
javac *.java
```

4. Run the program:

```
java Main
```

## Output

The program allows the user to:
